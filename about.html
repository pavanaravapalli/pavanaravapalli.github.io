About

About me

I help build the software that lets companies run their own cloud services. I work on the behind-the-scenes parts that make virtual machines and other resources easier to create, manage and keep running.

How I got into this

My cloud journey began at C-DAC, where I worked on cloud and grid computing. I was drawn to the challenge of making complex computing infrastructure easier for government organizations to use in their data centers.

Since then I've worked across the layers needed to build and run private and hybrid clouds: management server, hypervisors (XenServer, VMware and KVM), virtual routers and networks, primary and secondary storage, clusters and high availability.

Open source

I contributed S3 functionality to Eucalyptus Cloud a decade ago. Recently I added UEFI support for guest VMs to Apache CloudStack: the hypervisors already supported it, but CloudStack didn't let users configure it, so I filled that gap (pull request #3638, released in 4.14).
