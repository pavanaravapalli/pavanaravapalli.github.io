UEFI support for guest VMs in Apache CloudStack

The hypervisors underneath CloudStack already supported UEFI, but CloudStack didn't let users configure it. I filled that gap, so users can now boot guest VMs with UEFI, a modern boot option that today's operating systems and workloads increasingly need.
